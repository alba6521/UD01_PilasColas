# 📚 Pilas y Colas en Java

## 🎯 Objetivos
Implementar las estructuras dinámicas **Pila (LIFO)** y **Cola (FIFO)** en Java.
Crear una clase **Nodo** y reutilizarla tanto en la Pila como en la Cola.
Invertir un texto usando exclusivamente operaciones de una pila.
Simular una fila de clientes atendidos por orden de llegada con un menú de consola.
Comprobar si una palabra o frase es palíndroma usando pila y cola a la vez.
Convertir un número decimal positivo a binario mediante una pila.

## 🛠️ Tecnologías
Java
GitHub

## 📋 Requisitos del Proyecto
No se permite el uso de `Stack`, `Queue` ni `LinkedList` de Java.
No se permite el uso de utilidades de inversión directa como `reverse()`.
Implementar las operaciones `push`, `pop` e `isEmpty` en la pila.
Reutilizar la clase `Nodo` en Pilas y Colas.
Comentar el código y nombrar los ficheros sin espacios ni caracteres especiales.
